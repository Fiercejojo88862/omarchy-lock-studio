Omarchy Lock Studio

A local web app that customizes the Omarchy lock screen with a live preview — and never breaks your ability to unlock.

Source on GitHub What is Omarchy?

Install

git clone https://github.com/Fiercejojo88862/omarchy-lock-studio.git
cd omarchy-lock-studio
./install.sh

omarchy plugin clone omarchy.lock   # one time: the view it edits
omarchy-lock-studio                 # opens 127.0.0.1:8731

What it does

ClockFormat, seconds, date, timezone, size, top or bottom.
TypographyText font, separate clock font, weight and letter spacing.
ProfileName, avatar, hostname and an editable welcome line.
Dev quotesThirty quotes rotating at your interval, sized how you like.
MediaMPRIS now-playing title, artist and cover art.
BackgroundImage picker with upscaling, blur and dim.
Text colorTheme, custom hex, or auto-picked from the background.
AuthenticationFace unlock on the IR camera and fingerprint reader, with live hardware status, enroll, test and toggle.
SafetyBackup before every write, restore any backup or stock.

How it stays safe

  • Edits only your own clone in ~/.config/omarchy/plugins/<you>.lock/, never /usr/share/omarchy.
  • Keeps the password field and PAM authentication signals intact. Biometrics — face on the IR camera, fingerprint via fprintd — only add a way in; the password stays the fallback.
  • Writes a timestamped backup of LockView.qml before each change.
  • One lock plugin only: the Wayland session lock has a single owner. Running a second lock plugin silently wins the session, so disable it first (omarchy plugin disable <id>).
